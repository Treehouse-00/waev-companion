# waev-companion

Release wheels for **waev.companion**, the Waev web companion OpenHop plugin.

Each GitHub release here carries one wheel (`waev_companion-<version>-py3-none-any.whl`),
its `SHA256SUMS` and `THIRD_PARTY_NOTICES.md`. The source lives in the Waev
repository; every release's notes record the exact source commit it was built from.

Install: in the OpenHop console, Plugins → Install plugin wheel → choose the wheel,
enable it, open Waev, sign in, and choose a companion on Settings › Connection.
